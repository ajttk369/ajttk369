# 안녕하세요, 웹 구현과 디자인/영상 작업을 함께 하는 유종안입니다.

웹 화면을 구현하고 필요한 기능을 붙이며, 디자인과 영상 콘텐츠까지 함께 다루는 작업을 합니다.  
HTML/CSS/JavaScript 기반의 반응형 웹 구현을 중심으로 LMS 유지보수, 데이터베이스 관리, Photoshop·Illustrator 디자인 작업, Premiere Pro·After Effects 영상 편집, Blender 작업까지 경험을 넓혀가고 있습니다.

## About Me

- 웹 퍼블리싱과 프론트엔드 구현을 중심으로 작업합니다.

- 사이버평생교육원에서 LMS 개발 및 유지보수, 서버 관리, 학생 데이터 관리 업무를 경험했습니다.
- HeidiSQL을 활용해 데이터베이스 조회, 수정, 운영 데이터 관리 업무를 수행했습니다.
- Photoshop, Illustrator, Premiere Pro, After Effects, Blender를 활용해 디자인/영상/3D 결과물도 제작합니다.
- 사용자가 보기 편한 화면과 실제로 동작하는 결과물을 만드는 데 관심이 있습니다.

상품 목록, 브랜드, 이벤트, 검색, 마이페이지 등 쇼핑몰 화면 흐름을 구성했고, Python을 활용해 상품 데이터 처리와 간단한 백엔드 구조를 경험했습니다.

카메라를 통해 컵을 인식하고 재질에 따라 분류하는 흐름을 구현했습니다.

### Smart Parking System
Arduino, NFC, Bluetooth를 활용한 스마트 무선 주차 시스템 프로젝트입니다.  
주차 상태 확인 흐름을 구현했고 교내대회에서 금상을 수상했습니다.
