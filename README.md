# 안녕하세요, 웹 구현과 디자인/영상 작업을 함께 하는 유종안입니다.

웹 화면을 구현하고, 필요한 기능을 붙이며, 디자인과 영상 콘텐츠까지 함께 다루는 작업을 합니다.  
HTML/CSS/JavaScript 기반의 반응형 웹 구현을 중심으로, Photoshop·Illustrator 디자인 작업과 Premiere Pro·After Effects 영상 편집, Blender 3D 작업까지 경험을 넓혀가고 있습니다.

## About Me

- 웹 퍼블리싱과 프론트엔드 구현을 중심으로 작업합니다.
- HTML, CSS, JavaScript 기반의 반응형 웹사이트를 만들 수 있습니다.
- LMS 개발 및 유지보수, 서버 관리, 업무용 웹/앱 개발 등 약 1년의 실무 경험이 있습니다.
- Photoshop, Illustrator, Premiere Pro, After Effects, Blender를 활용해 디자인/영상/3D 결과물도 제작합니다.
- 사용자가 보기 편한 화면과 실제로 동작하는 결과물을 만드는 데 관심이 있습니다.

## Projects

### Portfolio
개발, 디자인, 영상, 3D 작업을 한 번에 보여주는 개인 포트폴리오 사이트입니다.  
반응형 레이아웃, 프로젝트 상세 모달, 디자인 작업 라이트박스, 라이트/다크 모드를 구성했습니다.

### AI Future Expo
AI 전시 홍보를 위한 반응형 웹사이트입니다.  
HTML, CSS, JavaScript로 구성하고 Vercel에 배포했으며, 페이지에 사용된 영상 콘텐츠는 Premiere Pro와 After Effects를 활용해 제작했습니다.

### Shopping Mall Page
쇼핑몰 서비스를 가정해 제작한 웹 페이지입니다.  
상품 목록, 브랜드, 이벤트, 검색, 마이페이지 등 쇼핑몰 흐름을 구성했고 Python을 활용한 백엔드 작업도 경험했습니다.

### Automatic Cup Collector
Raspberry Pi, Python, Machine Learning을 활용해 컵을 인식하고 분류하는 자동 인식 컵 수거기 프로젝트입니다.

### Smart Parking System
Arduino, NFC, Bluetooth를 활용한 스마트 무선 주차 시스템 프로젝트입니다.  
주차 상태 확인 흐름을 구현했고 교내대회에서 금상을 수상했습니다.
